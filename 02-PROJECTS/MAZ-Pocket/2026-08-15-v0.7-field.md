# 2026-08-15 — MAZ Pocket v0.7 FIELD

Status: **implementation PR candidate; exact-head CI and physical hardware validation are separate gates.**

## Why this version exists

v0.6 solved install/pair/update friction. v0.7 makes the same six-surface device more useful away from the desk without turning the ESP32 into a heavy app/dashboard platform.

## v0.7 scope

### NOW
Home's compact status strip becomes **NOW** and shows one priority in order: agent question, queued Outbox, active shift, due reminder, received Beam, stale/waiting agents, Core offline, otherwise READY/FIELD READY.

### Quick 1–4
Keys 1–4 are persistent safe action identifiers. Defaults: TALK / NOTE / LAP / BEAM. Fn+number cycles a fixed allow-list; there is no user script/shell field.

### Context Ask
Fn+Space from almost any screen captures only a bounded snapshot of the focused app/item, opens COMM while Space remains held, records the question, and sends screen context as explicitly untrusted evidence. Context Ask cannot trigger deterministic PC/reminder execution merely because words resemble a command.

### Offline Outbox
Existing durable `outbox` records become an automatic oldest-first retry service for normal COMM WAVs, contextual WAVs and outgoing Beams. It reuses the single Host worker and bounded 15s→5m retry backoff. Failed work remains visible rather than disappearing.

### Beam
Short text/URLs move laptop ↔ Pocket. Core persists laptop→Pocket queue/history; Pocket→laptop is locally queued first and copied/saved on Windows when delivered. Incoming material is data only. v0.7 deliberately does not implement arbitrary files or remote execution.

### Laptop status
CONTROL gets a one-shot/cached laptop snapshot: CPU, RAM, NVIDIA GPU use/VRAM/temp when available, battery/charging and Ollama loaded model/VRAM/context. No continuous telemetry daemon is added to either side.

### FIELD + Shift
Fn+F enables FIELD mode: less background refresh and earlier screen dim while retaining Outbox/Beam usefulness. FLOW gets a Shift Clock that saves completed elapsed time to the existing record store.

### Local AI resource policy
`MAZ_AI_PROFILE` is separate from LOCAL/AUTO/CLOUD routing:
- SMART: ordinary 4096 context, adaptive 6144/8192 only when grounded prompt size needs it, ~5m model keep-alive.
- SAVE: small context and immediate unload after response.
- FAST: adaptive context and ~30m warm model.

Ollama timing/token/context metadata is retained so future optimisation is evidence-driven rather than based on guesses.

## Release candidate packaging

Exact-head GitHub Actions must emit:
- `MAZ-Core-v0.7.zip`
- `MAZ-Cardputer-v0.7.zip`
- `MAZ-Pocket-v0.7-Install.zip`
- raw M5Launcher `.bin`
- SHA-256 evidence

The combined ZIP contains both standalone halves. This requirement is now a permanent repository rule.
