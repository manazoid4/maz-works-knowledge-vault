# Maz Works Knowledge Vault — Windsurf Rules

This repository is Manazir Hussain's shared Maz Works memory: project status, research, client work, experiments, reusable patterns, and session handoffs in plain Markdown.

## Start order

1. Read `AGENTS.md`.
2. Read the relevant `wiki/projects/{project}/` notes.
3. Use `wiki/hot.md` when recent cross-project context matters.
4. Read a selected skill's complete `SKILL.md` before applying it.

## Critical rules

- Never modify `.raw/`; it is immutable source material.
- Use Obsidian wikilinks for internal knowledge links.
- Keep `wiki/log.md` append-only.
- Refresh `wiki/hot.md` rather than growing it indefinitely.
- JobFilter is one project, not the vault identity.
- Never store credentials, private client information, or private spiritual content.

Run `bash bin/setup-multi-agent.sh` to expose the skills to compatible agents. The canonical repository is <https://github.com/manazoid4/maz-works-knowledge-vault>.
