# Script

**0–6s — failure + constraint**  
“This car park asks for an app. Down here, my phone has [measured result]. I used public Derby pages only. No account, no scraping.”

**6–14s — number**  
“In an RAC survey, 73% of parking-app users reported a problem. Of those people, 70% cited unreliable signal.”

**14–23s — fairness**  
“Cashless parking can be convenient. Machines cost money and get damaged. The unreasonable bit is making connectivity the only obvious path where connectivity is unreliable.”

**23–44s — build**  
“So I made an unofficial offline reference. Install it while online; the location code, current tariff source and phone/web alternatives stay readable in airplane mode. I rejected pretending it could take payment offline, because it cannot.”

**44–53s — limitation**  
“The bit I couldn’t fix is the payment provider. This reduces the information failure. It does not make the transaction offline.”

**53–57s — sign-off**  
“It’s on the site. The code’s there too.”

Replace bracketed words only with a filming-day measurement. If the phone has service, change the episode or location; never stage zero bars.
