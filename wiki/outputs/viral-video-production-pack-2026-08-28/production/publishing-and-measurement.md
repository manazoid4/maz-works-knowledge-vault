# Publishing and Measurement

## Surface versions

- TikTok/Instagram/YouTube Shorts: 45–75 seconds, vertical, burned captions.
- LinkedIn: native upload; text explains the constraint and limitation. Do not paste a YouTube link as the post.
- Reddit: no campaign drop in research communities. If a current community permits it, write a native build post, disclose ownership, link the working artefact, and do not gate it.
- Episode page: video, short write-up, source note, live demo, repository, then optional compliant signup.

## LinkedIn Page repair checklist

Human action: choose/buy domain, replace capability-list description with buyer problems, use the smallest accurate company-size band, set Derby/England, add plain-language specialties, associate the personal profile, and point the custom button to contact. Verify signed-in fields and mobile cover crop before posting.

## Measurement sheet columns

Episode; publish date; surface; 3-second hold; retention at 25s; completion; episode-page clicks; demo clicks; repo clicks; opt-ins; practitioner comments; surviving Reddit threads; episode-cited enquiries; notes; next change.

Change one variable per episode. If retention fails before the fairness beat, adjust the opening. If retention holds but clicks fail, adjust the episode-page promise. If clicks hold but enquiries fail, inspect the offer and audience fit.
